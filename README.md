# Homebrew Tap for Stratos

Official Homebrew tap for **[Stratos](https://stratosapp.dev)** — the 100% native Swift macOS local development environment for PHP 8.1–8.5, Laravel, WordPress, and Node.js.

## Install via Homebrew

```bash
brew tap khorshedobs/stratos
brew install --cask stratos
```

## Upgrade

```bash
brew upgrade --cask stratos
```
